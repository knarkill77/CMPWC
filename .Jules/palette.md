# Palette's Journal - Elite 8 Duals

## 2025-05-15 - Initial UX/A11y Audit
**Learning:** The initial implementation lacks basic accessibility features like a "Skip to Content" link, semantic `<main>` tag, and proper ARIA attributes for the mobile menu toggle. Additionally, interactive elements like the contact email are not as functional as they could be (plain text instead of `mailto:`).
**Action:** Implement global accessibility improvements including skip-link, semantic structure, and ARIA enhancements.
