## 2025-05-15 - [Skip Link and Mobile Menu ARIA Polish]
**Learning:** Adding a "Skip to content" link and proper ARIA attributes (`aria-expanded`, `aria-controls`) to mobile menus significantly improves keyboard and screen reader accessibility with minimal code impact (< 40 lines).
**Action:** Always include a skip link as the first focusable element and ensure toggle buttons for menus have dynamic ARIA labels and states.
