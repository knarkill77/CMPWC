## 2025-05-14 - Mobile Menu Accessibility & Interactive Link Polish
**Learning:** Interactive elements like mobile menu toggles require explicit ARIA attributes (`aria-expanded`, `aria-controls`) and user-friendly labels to be accessible. Additionally, plain text contact information (emails) should always be converted to actionable links (`mailto:`) to reduce friction for users.

**Action:** Always verify that toggle buttons have dynamic ARIA states and that contact details use semantic, interactive elements.
