## 2025-05-15 - Enhancing Mobile Navigation Accessibility
**Learning:** Icon-only toggle buttons in mobile menus require explicit ARIA labels and state indicators (`aria-expanded`, `aria-controls`) to be usable by screen reader users. Additionally, adding `scroll-behavior: smooth` to the `html` element significantly improves the perceived quality of internal page navigation.
**Action:** Always include ARIA attributes for mobile menu toggles and implement smooth scrolling for landing pages with anchor links.
