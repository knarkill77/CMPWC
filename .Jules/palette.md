## 2025-05-15 - [Accessibility & Navigation Enhancements]
**Learning:** In a single-page scrolling site, smooth scroll behavior combined with skip-to-content links and clear focus states significantly improves the experience for both mouse and keyboard users. Skip-to-content links should be visually hidden by default but become visible on focus to assist screen reader and keyboard-only users without cluttering the UI for others.
**Action:** Always ensure `scroll-behavior: smooth` is set for anchor-heavy landing pages and provide skip-links targeting the main content area.
